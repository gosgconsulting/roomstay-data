# Create Make.com Workflow using MCP

This guide shows how to create the Make.com workflow using Make MCP (Model Context Protocol).

## Overview

Instead of using direct API calls, we use Make MCP which provides a cleaner interface for creating scenarios.

## Prerequisites

- Make MCP server configured
- Team ID: `595770`
- Report ID: `4b41d292-13f7-4695-81f9-0b4ee1761c9f`
- Report Name: `Metasearch Results`

## Creating the Workflow

The workflow will be created using Make MCP with the following structure:

1. **Webhook Trigger** - Custom webhook to trigger the workflow
2. **HTTP Module** - Get last 7 days data from API
3. **Claude AI Module** - Analyze the data
4. **Slack Module** - Send results to Slack

## Blueprint Structure

The blueprint follows Make.com's format with:
- `flow`: Array of modules
- Each module has: `id`, `mapper`, `module`, `version`, `metadata`, `parameters`
- Modules are connected via IDs in the flow

## Usage

The blueprint is generated by the server endpoint:

```bash
POST /api/make/create-scenario
```

This returns the blueprint structure that can be used with Make MCP.

## Next Steps

1. Get the blueprint from the API endpoint
2. Use Make MCP to create the scenario:
   ```javascript
   mcp_make_scenarios_create({
     teamId: 595770,
     blueprint: blueprint,
     scheduling: { enabled: false }
   })
   ```

## Manual Alternative

If MCP is not available, use the manual setup guide: `CREATE_WORKFLOW_MANUAL.md`
